Como um dispositivo se autentica

  1. Envia Authorization: Bearer com a chave e o cabeçalho X-Device-Id.
  2. A API compara o hash da chave; o valor original nunca fica guardado.
  3. Chave errada recebe 401, a leitura é descartada e o evento vai para o registro.
  4. Depois de 10 chaves erradas em um minuto, a origem recebe 429 e para de gerar registros, evitando inundar o log.
